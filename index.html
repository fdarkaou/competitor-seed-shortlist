Competitor seed shortlist

Who are the closest competitors of each of your iOS apps? PeekPanda can seed a starter preview with one app and return up to five potential competitors, each with the reason it matched (shared searches, similar listing, similar description or, weaker, same category). Paste one or more of those previews here and this page lays them out per app with ratings and live paid ads, lists competitors that show up for more than one of your apps, and, given last week's file, what joined or left. Nothing leaves your browser; this page never calls the API.

Where to get the JSON

The preview comes from PeekPanda, an iOS competitor catalogue where every app has a case file of dated, stored evidence. It needs a PeekPanda account (scope context:read), counts as one call toward your plan's daily API and MCP allowance, and never starts collection. See Preview a starter board; to find a store ID by name use GET /v1/starter-boards/search?query=...:

curl 'https://api.peekpanda.com/v1/starter-boards/app-493145008' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" > preview.json

The answer contains a seed.previewToken used to adopt the set as a board within 24 hours. You can leave it in; this page ignores it and never stores anything.
